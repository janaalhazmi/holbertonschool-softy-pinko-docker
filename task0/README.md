# Docker - Task 0: Create Your First Docker Image

## Description

This project is an introduction to Docker.  
The goal of this task is to create a Docker image using a `Dockerfile` based on the latest Ubuntu image.

The Docker image:
- Uses the latest Ubuntu image.
- Updates the APT package list.
- Upgrades the installed packages.
- Prints `Hello, World!` when the container is run.

## Requirements

- Docker installed and running.
- Ubuntu latest Docker image.
